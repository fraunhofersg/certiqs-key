# References

`refs/index.json` is the only citable source of the contracts: a claim
cites a work by its `ref_id` with a locator, and `refs/references.bib` is
generated from the index (`python harness/generate_bibliography.py`).
Each entry holds the bibliographic data and the version it refers to (an
arXiv version or a DOI); the works themselves are not distributed here.
