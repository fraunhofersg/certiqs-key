\begin{definition}\label{def:base}
  A state on $\Hs{\Qsys}$ carries the flag weight $\Wflag$, the module-local
  mark $\Loc$ and the reserved symbol $\Res$. Standard commands such as
  $\sum_{s} \Pi_s$, \emph{emphasis} and \ref{def:base} are allow-listed.
  % \Nevermentioned lives in a comment and is not a use.
\end{definition}
