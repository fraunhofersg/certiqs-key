The bound is the reason the object is useful; it follows from the defining
identity in one line.

\begin{theorem}\label{thm:bound}
Under Assumption~\ref{ass:leaf}, every base object of
Definition~\ref{def:object} satisfies $x \le 1$.
\end{theorem}

\begin{proof}
By \eqref{eq:object}, $x = 1 - y \le 1$.
\end{proof}
