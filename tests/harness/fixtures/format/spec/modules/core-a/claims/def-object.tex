\begin{definition}\label{def:object}
A \term[a pair of reals whose coordinates sum to one]{base object} is a pair $(x, y)$ of reals with
\begin{equation}\label{eq:object}
  x + y = 1 ,
\end{equation}
as in \cite[Def. 1]{alpha2020work}.
\end{definition}
