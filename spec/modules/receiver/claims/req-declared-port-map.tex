\begin{requirement}\label{req:declared-port-map}
The engine takes the \tref{detector ports} as a declared input
(\iface{port_map}) and never infers them from the \tref{instrument matrix}:
by Remark~\ref{rem:unmonitored}, the partition of the output modes into
``in some port'' and ``in no port'' has no observable content beyond the port
Grams it produces.
\end{requirement}
